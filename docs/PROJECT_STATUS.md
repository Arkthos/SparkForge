# SparkForge project status

**As of:** 2026-11-11.
**Position:** the clean, self-contained software and public-research snapshot
is published. The native assisted factory remains experimental, not deployment-qualified.

The publication contains project-owned code, source-neutral documentation,
synthetic fixtures and reviewed public-source research. Private source captures,
runtime journals, raw transcripts, archives and original private Git history
are excluded. No private collection is needed to run the test suite.

## Implemented

- Native agent/skill instructions drive intake, source/code inspection,
  reuse/update/new assessment, a concrete spec, manual decision, implementation,
  real checks, independent review, bounded correction and handoff.
- The knowledge helper verifies explicitly selected indexed local inputs,
  returns bounded text/citations and retains current coverage `NOT_ASSESSED`.
- The core uses strict specs and a separate transactional journal, real
  subprocess checks, finite limits and current-candidate review context.
- Profile assembly exports only owned resources; local structural validation
  does not establish Corp or Acro compatibility.
- Host-record/storage preparation tools and a fictional offline preview remain
  available, with their own deliberately narrow evidence ceilings.
