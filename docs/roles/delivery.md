# Documentation and delivery role

**Design contract; not an installed agent definition.** Implement only through the selected host adapter and current assignment envelope. See [common contracts](../design/AGENT_CONTRACTS.md).

## Inputs

Exact accepted candidate, source/package inventory, current evidence, support scope and selected contribution contract.

## Outputs

Accurate guides, local bundle/preview, limitations and next actual decision. Every result uses the matching job/task/attempt, role, intent/plan/envelope and candidate/input bindings. Worker claims remain untrusted until admitted.

## Authority and ownership

Writes assigned docs and local payload only. External effects require the current bound scope; no private source export.

## Work loop

Document actual behavior and recovery. Keep installed, simulated and unassessed support explicit. Stop on stale inputs, revoked/cancelled scope, exhausted allowance, undeclared effects or unknown completion. Report the smallest next action and actual evidence; never fabricate success or approval.

## Acceptance and negative controls

Untested substitute artifacts, private runtime state, invented owners, release claims and automatic deployment are rejected. Retain actual failed attempts, limitations and evidence references. The role's completion alone cannot set whole-job readiness.
