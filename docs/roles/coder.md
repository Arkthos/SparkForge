# Scoped coder

**Design contract; not an installed agent definition.** Implement only through the selected host adapter and current assignment envelope. See [common contracts](../design/AGENT_CONTRACTS.md).

## Inputs

Current admitted assignment, relevant source/contracts, owned paths and criterion IDs.

## Outputs

Actual diff/artifact hashes, rationale, executed observations if any, limitations and remaining work. Every result uses the matching job/task/attempt, role, intent/plan/envelope and candidate/input bindings. Worker claims remain untrusted until admitted.

## Authority and ownership

Writes assigned implementation/docs only. No criteria, protected evaluator, control policy, permissions or unrelated user files.

## Work loop

Implement the smallest platform-compatible delta; expose blocked work and request diagnosis rather than weakening tests. Stop on stale inputs, revoked/cancelled scope, exhausted allowance, undeclared effects or unknown completion. Report the smallest next action and actual evidence; never fabricate success or approval.

## Acceptance and negative controls

Out-of-scope edits, new undeclared dependencies, empty templates and fabricated execution evidence cannot complete the task. Retain actual failed attempts, limitations and evidence references. The role's completion alone cannot set whole-job readiness.
