# Target environment acceptance

**NOT_ASSESSED for real corp and acro.** Structural profiles and source-neutral tests do not establish support. Use this protocol at the relevant live milestones, not as a blocker for P1-P5 development.

| Evidence category | Required target-local record |
|---|---|
| Host/capabilities | Exact host/build/profile, actual agent dispatch/discovery, supported tools, producer context, usage and stop/recovery capabilities |
| Platform knowledge | Supported interfaces/component types, selected authorized source revisions, actual freshness/permission limits |
| Data/resource envelope | Local paths/store/provider routes, actual identity/permissions, finite model/tool trial allowance and retention |
| Package lifecycle | Exact package inventory/digest, installed-source operation, relocation, upgrade/remove and preserved user data |
| Behavioral journeys | New/reuse/update, defect repair, passing-but-wrong drift, independent review, feedback and interruption |
| Control boundaries | Protected acceptance, actual tool/effect mediation, cancellation/revocation/unknown effects and negative probes |
| Acceptance/support | Genuine domain/control decisions, observed performance/usage, accountable support scope and unresolved risks |

For corp use WP-163 through WP-165 after the native adapter/lifecycle gates. For acro use WP-180/WP-181 with its own context and receipts. Acro may use reviewed shared code without importing corp credentials, source snapshots, journals or model memory. No live bridge or automatic cross-environment synchronization is designed.

Keep sensitive records in the selected environment. Publish only permitted source-neutral aggregate outcomes with scope/limits. An environment label, host consistency record, AI summary or another target's success cannot supply acceptance.

If qualification fails, fix the specific cause and rerun affected evidence, narrow the claimed support, or request a material architecture/authority decision. Do not keep retrying under another account/provider or substitute a mocked result.
